The funniest sign for the door of a haunted server room: "PLEASE KNOCK: the ghost is rebooting. The last admin who did not is now a cable in Rack 2."

## Run it

```sh
node main.ts
```

## Why this line

Pure sign format ("PLEASE KNOCK") that a ghost would tape to the door; the haunting is specific and fresh (a ghost mid-reboot, and the last admin who skipped the knock is now a cable in Rack 2); the sting lands on the final words. It collides office IT life (reboot, Rack 2, admin) with the supernatural in one glanceable line — 90 characters, clean to read aloud.
